## Основные проекты

### [linux-automa / Fileward](https://github.com/g1nry/linux-automa) — основной проект

Демон на C для автоматизации файловой системы Linux. Отслеживает события в каталогах через `inotify`, сопоставляет их с правилами и выполняет действия: копирование, перемещение, архивирование файлов и запуск команд.

- Работа в виде службы **systemd**, перезагрузка правил и проверка состояния процесса.
- Структурированный **JSONL-журнал** событий и результатов действий.
- Очередь задач, пул потоков, таймауты и повторные попытки выполнения.
- Шаблоны конфигурации для **Wazuh** и адаптер данных для **Shuffle** как основа дальнейшей интеграции с SIEM/SOAR.

Развиваю проект в сторону передачи событий в системы мониторинга и построения сценариев реагирования на инциденты. Проверка полной цепочки на стенде — следующий этап интеграции.

**Технологии:** C · Linux · inotify · systemd · POSIX Threads · JSONL · Meson · Ninja

### [rag_agent](https://github.com/g1nry/rag_agent) — RAG-система с агентными возможностями

Сервис, объединяющий поиск по загруженным документам и LLM-агента, который может вызывать инструменты для работы с файлами и выполнения команд. Использую проект для экспериментов с агентными сценариями и исследования безопасности LLM.

- Поиск релевантного контекста в документах для формирования ответа.
- Агент на **LangGraph** с циклом рассуждения и вызова инструментов.
- HTTP API на **FastAPI** и работа с локальными моделями через **Ollama**.

**Технологии:** Python · FastAPI · LangChain · LangGraph · Ollama · Docker

### [load_web_testing](https://github.com/g1nry/load_web_testing) — нагрузочное тестирование веб-приложений

Набор сценариев и скриптов для проверки производительности и устойчивости веб-приложений. Предназначен для тестирования собственных систем или систем, на проверку которых получено разрешение владельца.

- Профили нагрузки: smoke, пропускная способность, CPU, память, сеть и поиск предела производительности.
- Автоматизация запусков, сбор результатов и формирование отчётов.
- Подключение метрик **Prometheus** для сопоставления нагрузки с состоянием приложения и сервера.

**Технологии:** k6 · JavaScript · Bash · Python · Prometheus
